# Changelog

## 0.2.0

- Added the controlled `RepoCanvasEditor` and imperative editor/canvas handles.
- Added read-only, theme, locale, grid, image-tool, branding, and layout customization.
- Added a collapsible, preference-aware whiteboard index with a keyboard shortcut.
- Added search, tags, project scope, templates, thumbnails, mobile action menus, and resource links.
- Added PNG, SVG, clipboard, RepoCanvas JSON, and Excalidraw JSON interoperability.
- Added capped autosave retry, navigation flushing, stale-session protection, and browser recovery journaling.
- Added IndexedDB and HTTP adapters, cross-tab LocalStorage refresh, transactional rollback, metadata revisions, paging, subscriptions, and adapter conformance verification.
- Added runtime document validation/migration, deterministic serialization, and a CLI.
- Added split package entry points, MIT licence, CI, component/browser tests, and integration documentation.

## 0.1.3

- Initial public package with whiteboard library, Excalidraw canvas, storage adapters, autosave, conflicts, recovery, fullscreen, and Pencil/touch policy.
